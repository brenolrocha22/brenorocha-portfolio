## Problema

Responder três perguntas de negócio a partir de uma base crua de vendas:

1. Quais famílias de modelos sustentam a receita?
2. Quanto as vendas dependem de crédito?
3. Quanto da receita ainda não foi entregue?

## Solução

Um pipeline em Python (`sanitize_porsche.py`, `prepare_base.py` e `build_html.py`) trata a base e gera um **dashboard em um único arquivo HTML**, com:

- filtros interativos;
- link compartilhável que guarda os filtros na URL (por exemplo, `?familia=911&estado=CA`);
- painel de qualidade do dado.

Os nomes de pessoas são removidos antes de a base ser embutida na página. O prompt usado no processo está documentado no repositório.

## Arquitetura

1. `data/`: base bruta, base tratada e base final em JSON.
2. `agents/`: scripts Python de tratamento e geração.
3. `src/dashboard.template.html`: modelo que vira o `index.html` publicado no GitHub Pages.

## Limitações

- A base tem apenas 100 linhas de dados de laboratório da DIO.
- Não há testes automatizados do tratamento.
